# LibrosUy 📚

Find any book in Uruguay. LibrosUy searches local bookstores for in-stock titles and connects readers with vendors who can import niche or international books. 

This project is built with a **FastAPI (Python)** backend, a **React + Leaflet** frontend, and an **SQL Server** database.

---

## ⚙️ Prerequisites
Before running this on your local Windows machine, ensure you have the following installed:
* **Python 3.x** 
* **Node.js & npm** 
* **SQL Server** (SQL Server Express or Developer Edition)
* **Git**
